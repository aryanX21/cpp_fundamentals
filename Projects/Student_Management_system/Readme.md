# Student Management System

A simple console-based Student Management System developed in C++ to manage student records.

## Features

* Add Student
* Display Students
* Search Student
* Update Student
* Delete Student
* Save Data to File
* Load Data from File

## Concepts Used

* Classes and Objects
* Constructors
* Functions
* Strings
* File Handling
* Object-Oriented Programming (OOP)

## Language

C++
